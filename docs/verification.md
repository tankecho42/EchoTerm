Release 构建位于 `dist/EchoTerm.app`，版本 0.4.0。应用在临时目录中签名后放到 `~/Library/Application Support/EchoTerm/Builds`；`dist/EchoTerm.app` 是链接，另提供 `dist/EchoTerm.zip`。Documents 的 File Provider 会重新附加 FinderInfo，故不把可运行实体存放在那里。替换整个构建包避免覆盖正在运行的可执行文件。实体、dist 链接及 ZIP 解压后的 App 均通过 `codesign --verify --deep --strict`。

## 尚未覆盖

各真实模型 Provider 的生产接口需用用户凭据联调。不同模型的思考参数、工具调用和并发限制仍可能不同。当前检查不等于所有第三方网关均兼容。

保留的终端边界：普通 Block 为纯文本；完整 shell 补全、复杂 TUI / SSH、更多插件适配、历史恢复、Intel Mac、长期压力与发行公证尚未完成。
