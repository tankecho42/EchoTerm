# EchoTerm · 上下文流动

30 秒宣传片 v5，1920 × 1080，60 fps，H.264 + AAC。

成片：`output/EchoTerm-Promo-v5-30s.mp4`。

本版重做中段的查找叙事，移除底部「提问 / 查找会话 / 读取 Block / 跳转高亮」步骤条。持续存在的像素群从上一个镜头的「块」字出发，在提问区域汇成 Echo，随后沿空间路径找到另一会话，扫描区块索引，包围浮出的 Block 03，再汇入 `port = 4317` 的下划线。带着结果回到问题后，像素继续进入玻璃镜头，分成鸢尾和琥珀两束主题色，最终重新聚合并组成片尾字标。

| 时间 | 画面 |
| --- | --- |
| 0–8.4 秒 | 命令与问答，一个入口；原生 AI Native 终端 |
| 8.4–11.2 秒 | 像素从 AI 回答飞出，组成「块」字，再离开标题进入提问 |
| 11.2–15.7 秒 | 提问窗口拉远，显露另一个会话；像素束穿过场景，沿区块索引查找 |
| 15.7–19.7 秒 | 同一个 Block 03 从 S1 中浮出；镜头跟进，像素环绕边界并标出端口配置 |
| 19.7–21.7 秒 | 镜头退回会话全景，像素将结果带回当前问题，再向下一幕流动 |
| 21.7–25.8 秒 | 透明度和毛玻璃可调；像素分流串联雾蓝、鸢尾、琥珀窗口 |
| 25.8–30 秒 | 像素组成 EchoTerm，命令与 AI 无感衔接 |

## 动效实现

- 中段使用共享的三维坐标：窗口、Block、粒子与相机在同一空间中。选中的 Block 始终是同一图层，从原位置连续移动到前景，没有换成另一个放大截图。
- 相机使用连续 Hermite 曲线控制目标、距离、俯仰和环绕；中段衔接使用小角度转向，保留开场及片尾的大幅旋转。
- 168 个像素贯穿中段与外观镜头，保留粒子位置衔接，采用带相位差的细束流动。字体与原始终端内容保持清晰。
- 修正像素边缘的透明混合，避免深色轮廓；固定白熊主体的像素身份，避免表情装饰增减导致重排跳变。
- 配乐延续原有旋律，重新配置像素飞行的细颗粒音效，并降低中段转向的冲击声。

## 素材说明

这是实际界面素材与产品演示动画的合成，不是一镜到底的实时录屏。命令输出、配置与跨会话定位故事沿用已录制的演示；AI 使用本地脚本化 Provider，不代表远程模型实测速度。像素路径、三维会话展示与浮出的区块属于宣传片说明动画。玻璃和主题窗口沿用 v4 的合成方式，展示软件现有的透明度、三种玻璃材质及配色功能。基础录制与审计素材位于 `../stills`、`../footage` 和 `../source/demo-audit.jsonl`。

v4 原片已保留。这次只修改宣传片文件，没有修改或重启 EchoTerm 应用。

## 文件

- `source/render-film.py`：界面图层、相机、粒子路径、渲染与编码。
- `source/ExportPixels.swift` 和 `assets/echo-60fps.json`：1800 帧原生像素角色动画。
- `source/make-soundtrack.py`：原创配乐和音效。
- `source/verify-film.py`：媒体信息、帧数、完整解码和编码后关键帧检查。
- `source/flow-check.json`：中段逐帧轨迹检查。
- `source/media-check.json`：最终媒体验证记录。

使用 Python 3、NumPy、OpenCV、Pillow、Swift / AppKit 和 FFmpeg；本机 Python 运行时位于 `python3 (activated virtual environment)`，补充依赖位于 `/tmp/echoterm-video-python`。

## 验证结果

最终成片 30.000 秒、1920 × 1080、60 fps、1800 帧，H.264 / AAC 立体声，完整解码通过。已检查编码后的关键帧及接缝，逐帧核对 897 帧像素轨迹的有效性。配乐综合响度约 -17.8 LUFS、真峰值 -4.2 dBFS。最终渲染使用 4 个独立工作进程和最多 8 帧缓冲，按原始帧号顺序编码。
