# EchoTerm · 三主题连续流动

46 秒宣传片 v8，1920 × 1080，60 fps。

成片：`output/EchoTerm-Promo-v8-46s.mp4`。

本版重做主题展示部分的流动像素。像素从上一段回答直接进入三个窗口之间的装饰轨迹，沿玻璃边缘穿行，随关联窗口过渡为雾蓝、鸢尾和琥珀。窗口内部的像素降低可见度，形成从玻璃后方经过的效果；主题名称周围留白。装饰轨迹直接汇入片尾字标，中途不再组成 Echo 头像。

取消了原来抵达中间窗口后的停留，以及主题展示结束前的头像聚合。将原有 2.65 秒停留平滑地分配给整个主题镜头，使三个窗口持续展开，材质和透明度持续过渡。像素以成片时间行进，展示期间始终在流动。前面的入场、功能演示、查找与阅读停留保留，总时长仍为 46 秒。

## 实现

- 168 个像素沿同一条闭合曲线穿过三个窗口；曲线绑定窗口的实时位置和透视。
- 轨迹按长度采样，呈现连续流动。像素大小、间距和透明度形成三组柔和的流动亮点。
- 像素进入主题场景、开始循环以及汇入字标时都共用当前轨迹位置，保持连续性。
- 音乐和 SRT 按新的主题时间线同步；去除了对应的音乐停留空隙。

## 文件

- `source/render-film.py`：镜头、窗口、连续主题装饰动画与编码。
- `source/timing.py`：阅读停留及持续流动的主题段时间映射。
- `source/make-soundtrack.py`：原创配乐和音效。
- `source/check-theme-flow.py`、`theme-flow-check.json`：主题段逐帧运动与连接点检查。
- `source/verify-film.py`、`media-check.json`：最终编码与完整解码检查。
- `previews/encoded-contact.jpg`：编码后关键帧。

沿用已有真实界面素材、原生像素角色与程序化宣传动画；AI 演示使用脚本化 Provider。玻璃、会话空间和像素轨迹为宣传片合成。本次仅修改 `promo/v8`，应用和 v7 原片保留。

本机 Python：`python3 (activated virtual environment)`；依赖 NumPy、OpenCV、Pillow、FFmpeg 和随项目保存的 AppKit 字体工具。

## 成片验证

46.000 秒，1920 × 1080，60 fps，共 2760 帧；完整解码通过，已检查编码后的主题镜头与片尾。连续装饰段检查 318 帧，每帧的像素位移中位数最低约 3.66 像素，没有暂停；三个连接点的轨迹连续。配乐实测约 -17.38 LUFS、真峰值 -4.57 dBFS。
