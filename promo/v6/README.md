# EchoTerm · 上下文流动

41 秒宣传片 v6，1920 × 1080，60 fps，H.264 + AAC。

成片：`output/EchoTerm-Promo-v6-41s.mp4`。

本版保留 v5 的画面设计与流动像素叙事，重新调整停留节奏。新增的 11 秒集中在图形形成、选中区块、读出端口、返回答案及主题展示之后。转场的主要飞行速度保持原有节奏，进入与离开停留时连续减速、加速。没有重复插入静帧。Block 边缘的像素在停留时继续环绕流动。

## 实现

- `source/timing.py` 以严格递增的 C2 曲线将原有 30 秒编排映射到 41 秒。局部放慢完成态，保持运动轨迹与粒子身份连续；不依赖整片降低播放速度。
- 原生像素角色按子帧采样插值，眨眼依然采用直接切换。
- Block 边缘循环与小幅粒子旋转按成片时间运行，避免停留时像暂停画面。
- 音乐重新编排为 41 秒，降低节奏密度；停留时让旋律与低频节拍让位于持续和声。转场声、定位声和像素颗粒声与新时间线同步，未经变速或变调。
- 可选 SRT 字幕使用相同时间映射。

## 素材

沿用 v5：实际 EchoTerm 界面录制素材、原生 Swift 像素角色，以及三维镜头和说明动画。AI 演示使用本地脚本化 Provider；会话空间、浮出区块、流动像素与玻璃窗口属于宣传片合成。录制基于雾蓝主题、25% 透明度和通透玻璃；成片只表达透明度、玻璃材质可调与多种主题选择，不显示具体透明度值。

旧版 v5 保留。本次仅修改 `promo/v6`，没有修改或重启 EchoTerm 应用。

## 文件与复现

- `source/render-film.py`：画面、粒子、相机与编码。
- `source/timing.py`：统一的画面、音效与字幕时间映射。
- `source/make-soundtrack.py`：原创音乐与音效。
- `source/verify-film.py`：编码结果检查与关键帧导出。
- `source/pacing-check.json`：单调时间线、反向映射精度、逐帧像素轨迹及停留时长。
- `source/media-check.json`：最终媒体检查记录。
- `previews/encoded-contact.jpg`：编码后关键帧。

本机 Python：`python3 (activated virtual environment)`。依赖 NumPy、OpenCV、Pillow、FFmpeg，以及随项目保留的 Swift / AppKit 文字渲染器。运行 `make-soundtrack.py` 后用 FFmpeg loudnorm 生成 `soundtrack.wav`，再运行 `render-film.py --render` 与 `verify-film.py`。

## 成片验证

最终文件 41.000 秒、1920 × 1080、60 fps，共 2460 帧；H.264 / AAC 双声道 48 kHz。完整解码通过，已查看编码后的关键帧。画面时间映射严格递增，往返误差小于 0.000001 秒。归一化配乐实测约 -17.98 LUFS、真峰值 -5.05 dBFS。
